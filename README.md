# Bush Master of SPLORR!!

A small Metaphor by TheGrumpyGameDev: a fenced plot, a berry bush and a basket. Pick berries, drop them in the basket, collect jools. Odin compiled to WebAssembly, played in the browser.

Build and run: `tools/serve.sh` (needs Odin and Python 3), then open http://localhost:8000/. Tests: `tools/test.sh`.
